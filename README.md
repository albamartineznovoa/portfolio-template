# Mi Portfolio template

Este proyecto consiste en el desarrollo de una **plantilla de portfolio web profesional**, responsive y optimizada, realizada como **trabajo final de la asignatura Web**.

El objetivo es crear una base sólida, escalable y reutilizable que cumpla con criterios reales de producción web: buena estructura HTML, estilos modernos en CSS, animaciones sutiles, accesibilidad básica, control de versiones con Git y despliegue mediante GitHub Pages.

La plantilla está pensada para presentar proyectos de diseño gráfico, editorial, branding y motion, y puede adaptarse fácilmente a distintos perfiles creativos.

---

## Stack tecnológico

- **HTML5 semántico**
- **CSS3 moderno** (custom properties, Grid, Flexbox, `clamp()`)
- **JavaScript vanilla** para interactividad y lógica de la interfaz
- **Bootstrap 5 (CDN)** para estructura base y componentes
- **GSAP + ScrollTrigger** para animaciones y microinteracciones
- **Git & GitHub** para control de versiones
- **GitHub Pages** para despliegue

> Nivel elegido: **Grado 2 — Bootstrap + GSAP (sin build tools)**

---

## Estructura del proyecto

La arquitectura del proyecto está organizada de forma modular para facilitar su mantenimiento y reutilización en futuros portfolios.

---

## Funcionalidades principales

- Landing page con hero centrado y tipografía fluida
- Navegación fija con scroll suave por anclas
- Grid de proyectos responsive
- Modales dinámicos para cada proyecto:
  - Carrusel de imágenes
  - Galería en grid
  - Reproducción de vídeo
- Animaciones de entrada y scroll con GSAP
- Microinteracciones en hover y navegación
- Barra de progreso de scroll
- Página **404 personalizada**
- Formulario de contacto funcional (fallback a `mailto`)
- Accesibilidad básica:
  - Navegación por teclado
  - `prefers-reduced-motion`
  - Estructura semántica
  - Contraste adecuado

---

## Diseño y criterios técnicos

- Diseño **minimalista** en blanco y negro
- Jerarquía visual clara y espaciados amplios
- Uso de **CSS Grid** para layouts principales
- Uso de **Flexbox** para componentes y alineación
- Tipografía fluida mediante `clamp()`
- Variables CSS para colores, radios y espaciados
- Sistema visual consistente entre secciones
- Enfoque en legibilidad, ritmo y coherencia visual

## Instalación y uso

Este proyecto no requiere instalación ni proceso de build.

1. Clonar el repositorio:

```bash
git clone https://github.com/albamartineznovoa/portfolio-template.git
```

2. Abrir el archivo index.html en el navegador
   O acceder directamente desde GitHub Pages mediante la URL publicada.

## Despliegue

El proyecto está desplegado usando GitHub Pages desde la rama main.
Incluye una página 404.html personalizada para manejar rutas inexistentes.
