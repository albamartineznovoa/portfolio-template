# Mi Portfolio template

> by Alba

You can find the deployed site here: [https://albamartineznovoa.github.io/portfolio-template/] (https://albamartineznovoa.github.io/portfolio-template/)

Este proyecto consiste en el desarrollo de una **plantilla de portfolio web profesional**, responsive y optimizada, realizada como **trabajo final de la asignatura Web**.

El objetivo es crear una base sólida, escalable y reutilizable que cumpla con criterios reales de producción web: buena estructura HTML, estilos modernos en CSS, animaciones, accesibilidad básica, control de versiones con Git y despliegue mediante GitHub Pages.

## Stack tecnológico

- **HTML5 semántico**
- **CSS3 moderno** (custom properties, Grid, Flexbox, `clamp()`)
- **JavaScript vanilla** para interactividad básica
- **Git & GitHub** para control de versiones
- **GitHub Pages** para despliegue

> Nivel elegido: **Grado 1 — Vanilla (sin build, dependencias por CDN)**

## Funcionalidades principales

- Layout responsive (mobile-first)
- Grid de proyectos adaptable
- Navegación por anclas
- Animaciones CSS y microinteracciones
- Accesibilidad básica (contraste, estructura semántica)
- Página 404 personalizada

## Diseño y criterios técnicos

- Uso de **CSS Grid** para layouts principales
- Uso de **Flexbox** para componentes
- Tipografía fluida mediante `clamp()`
- Variables CSS para colores y espaciados
- Arquitectura CSS organizada y escalable

## Instalación y uso

Este proyecto no requiere instalación ni build.

1. Clonar el repositorio:

```bash
git clone https://github.com/tu-usuario/tu-repo.git
```

2. Abrir el archivo `index.html` en el navegador

O acceder directamente desde GitHub Pages mediante la URL publicada.

## Despliegue

El proyecto está desplegado usando **GitHub Pages** desde la rama `main`.
